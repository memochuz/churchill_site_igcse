## What is a Function? An Intuitive Idea

Before defining a function formally, it is helpful to think of a function as a **machine**.

A function takes an **input**, performs a specific operation, and produces an **output**.  
Whatever rule the machine follows, it always gives the **same output for the same input**.

   <img src="{{ site.baseurl }}/images/Functions/function_machine.png" alt="Function machine" width="700">
</p>

This process can be summarized as:

$$
\text{Input} \;\longrightarrow\; \text{Function} \;\longrightarrow\; \text{Output}
$$

For example, imagine a machine that multiplies every number by 2:
- Input: 3 → Output: 6  
- Input: 5 → Output: 10  

This idea of a machine helps us understand how functions work before introducing formal mathematical language.

---

## The Formal Definition of a Function

In mathematics, a **function** is defined more precisely.

> A function is a rule that assigns **exactly one output** to **each input**.

This means:
- Every input must have an output.
- No input can have more than one output.

If a single input produces two different outputs, the relation is **not a function**.

---

## Input, Output, and Rule of Correspondence

Every function has three essential components:

### Input

The **input** is the value that enters the function.  
It is usually represented by the variable $x$.

### Output

The **output** is the value produced by the function.  
It is often represented by $y$ or by $f(x)$, which means

 > $f(x) \Longleftrightarrow$ the output of the function when the input is $x$.

### Rule of Correspondence
The **rule of correspondence** describes how the input is transformed into the output.  
It is the mathematical operation performed by the function.

For example, if

$$
f(x) = 3x + 1,
$$

the rule of correspondence is “multiply the input by 3 and then add 1.”

---

## Function Notation

Functions are commonly written using **function notation**:

$$
f(x)
$$

This is read as *“f of x”* and represents the output of the function when the input is $x$.

If $ x = 2 $, then:

$$
f(2) = 3(2) + 1 = 7
$$

---

## Domain

The **domain** of a function is the set of **all possible input values**.

In other words, it includes every value that can be put into the function without causing any mathematical problems.

For example:
- If a function involves division by $x$, then $x = 0$ cannot be part of the domain.
- If a function works for all real numbers, then its domain is all real numbers.

> **Domain = all values that can be input into the function (these values depend on the function).**

---

## Range

The **range** of a function is the set of **all possible output values**.

It includes every value that the function can produce after applying the rule of correspondence to the domain.

For example:
- If a function always produces positive outputs, then the range consists only of positive numbers.

> **Range = all values that can be output by the function.**

## Summary

A function can be understood as a mathematical machine with clearly defined parts:

- **Input**: the value that enters the function  
- **Output**: the value produced by the function  
- **Rule of correspondence**: the operation that links input to output  
- **Domain**: the set of all possible inputs  
- **Range**: the set of all possible outputs  

Understanding these concepts is essential before working with tables, graphs, and equations of functions.
