#  Hard 🔴

Solve the following sequence problems:

> 1. An arithmetic sequence has $a_1 = 12$, $a_{20} = 88$. Find the common difference. 
> 2. The 5th term of an arithmetic sequence is $20$ and the 15th term is $50$. Find $a_1$. 
> 3. A geometric sequence has $a_1 = 81$, $a_2 = 27$. Find the common ratio and $a_5$. 
> 4. A geometric sequence has $a_1 = 2$, $r = \tfrac{1}{2}$. Find $S_{10}$. 
> 5. The terms are $2, 6, 12, 20, 30, \dots$. Find the formula for $u_n$. 
> 6. The sequence is $1, 9, 28, 65, 126, \dots$. Find the formula for $u_n$. 
> 7. Find $u_{12}$ if $u_n = n^2 + 3n - 4$. 
> 8. Find $u_{10}$ if $u_n = n^3 - 2n^2 + n$. 
> 9. Write the first five terms of $u_n = n^4$. 
> 10. Find $u_{6}$ if $u_n = n^4 - 2n^2 + 1$.
