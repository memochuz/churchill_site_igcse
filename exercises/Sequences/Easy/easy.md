#  Easy 🟢

Solve the following sequence problems:

> 1. Write the next three terms: $2, 4, 6, 8, \dots$ 
> 2. Find the 10th term: $3, 6, 9, 12, \dots$ 
> 3. Write the next three terms: $2, 4, 8, 16, \dots$ 
> 4. Find the 7th term: $5, 10, 20, 40, \dots$ 
> 5. Write the first five terms of the sequence $u_n = n^2$ 
> 6. Write the first five terms of the sequence $u_n = n^3$ 
> 7. Write the next three terms: $1, 4, 9, 16, \dots$ 
> 8. Write the next three terms: $1, 8, 27, 64, \dots$ 
> 9. Find $u_{10}$ if $u_n = 2n+1$ 
> 10. Find $u_{6}$ if $u_n = 3 \cdot 2^{n-1}$
