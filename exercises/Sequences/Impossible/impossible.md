# Impossible ⚫

Solve the following sequence problems:

> 1. An arithmetic sequence has $a_1 = -7$, $a_{25} = 93$. Find $d$ and $S_{25}$. 
> 2. The sum of the first 50 terms of an arithmetic sequence is $5000$. $a_1 = 15$. Find $d$. 
> 3. A geometric sequence has $a_1 = 729$, $a_6 = 1$. Find $r$. 
> 4. A geometric sequence has $a_1 = 5$, $S_{\infty} = 20$. Find $r$. 
> 5. A quadratic sequence is $3, 10, 21, 36, \dots$. Find $u_n$. 
> 6. A cubic sequence is $0, 2, 16, 54, 128, \dots$. Find $u_n$. 
> 7. Find $u_{15}$ if $u_n = n^4 - 3n^2 + 2n$. 
> 8. A quartic sequence is $1, 16, 81, 256, 625, \dots$. Find the formula. 
> 9. Find $u_{12}$ if $u_n = n^4 + 2n^3 - n^2$. 
> 10. A sequence is defined by $u_n = n^4 - 2n^3 + n^2 - n + 1$. Find $u_{8}$.
