# Medium 🟠

Solve the following sequence problems:

> 1. The first term is $5$ and the common difference is $4$. Find the 15th term. 
> 2. Find the sum of the first 20 terms: $7, 10, 13, \dots$ 
> 3. The first term is $3$ and the common ratio is $2$. Find the 8th term. 
> 4. The sum of the first 6 terms is needed: $2, 6, 18, \dots$ 
> 5. Find a formula for the $n$th term: $1, 4, 9, 16, \dots$ 
> 6. Find a formula for the $n$th term: $1, 8, 27, 64, \dots$ 
> 7. Write the first five terms: $u_n = n^2 + 2n$ 
> 8. Write the first five terms: $u_n = n^3 - n$ 
> 9. Find $u_{10}$ if $u_n = 2n^2 - 3n + 1$ 
> 10. Find $u_{7}$ if $u_n = n^3 + 2n$
