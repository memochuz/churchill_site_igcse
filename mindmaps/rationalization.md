# Rationalization

## **Case 1:** Single Radical in the Denominator
- **Step 1:** Identify Case 1
  - Denominator contains a single radical, e.g.  $\frac{3}{\sqrt{2}}$.
- **Step 2:** Multiply numerator and denominator by the radical
  - Use formulas:
    - $\sqrt{a}\sqrt{a}=a$
    - $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$
  - Example: 
    - $\frac{\sqrt{6}}{\sqrt{3}} \rightarrow \frac{\sqrt{6} \cdot \sqrt{3}}{\sqrt{3} \cdot \sqrt{3}} = \frac{\sqrt{18}}{3}$
- **Step 3:** Simplify
  - Use radical simplification rules: 
  $\frac{\sqrt{18}}{3} = \frac{\sqrt{3\times 3 \times 2}}{3} = \frac{3\sqrt{2}}{3}$
  - Reduce fractions if needed: 
  $\frac{3\sqrt{2}}{3} = \sqrt{2}$

---

## **Case 2:** Sum or Difference with Radicals in the Denominator
- **Step 1:** Identify Case 2
  - Denominator has two terms, at least one radical:
   $\frac{3}{\sqrt{2} + 1}$
- **Step 2:** Multiply numerator and denominator by the conjugate
  - Conjugate: the conjugat of $a - b$ is a $a + b$ and vice versa.
  - Apply formulas:
    - $(a+b)(a-b) = a^2 - b^2$
    - $\sqrt{a}\sqrt{b} = \sqrt{ab}$
  - Example:
    - $\frac{\sqrt{4}}{\sqrt{3} + 1} \rightarrow \frac{\sqrt{4}\cdot (\sqrt{3} - 1)}{(\sqrt{3}+1)(\sqrt{3}-1)} = \frac{\sqrt{12}-\sqrt{4}}{3-1} = \frac{\sqrt{12}-2}{2}$
- **Step 3:** Simplify
  - Use radical simplification rules: 
  $\frac{\sqrt{12}-2}{2} = \frac{\sqrt{2\times 2\times 3}-2}{2} = \frac{2\sqrt{3}-2}{2} = \frac{2(\sqrt{3}-1)}{2}$
  - Reduce fractions if possible: $\frac{2(\sqrt{3}-1)}{2} = \sqrt{3}-1$

---

## Sums and Subtractions of Rationalized Fractions
- **Step 1:** Identify the type of fractions
  - Check if denominators are Case 1 or Case 2
- **Step 2:** Rationalize each fraction
  - Apply Case 1 or Case 2 method as appropriate
- **Step 3:** Combine fractions
  - Find a common denominator
  - Add or subtract numerators
  - Simplify final expression using radical simplification rules
  - Example:
    - $\frac{1}{\sqrt{3}} + \frac{1}{\sqrt{2}+1}$
    - Rationalize each: 
      - $\frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$
      - $\frac{1}{(\sqrt{2}+1)} = \sqrt{2}-1$
    - Combine over common denominator if needed: 
      $\frac{\sqrt{3}}{3} + 3(\frac{\sqrt{2}-1}{3})= \frac{\sqrt{3}+3\sqrt{2}-3}{3}$
    - Simplify the result if needed.
